Sambungkan HP & Laptop

Penyebab Scanner HP Error / Force Close

Anda membuka file HTML ini secara langsung (lokal) dari komputer Anda (file:///...). HP Anda tidak bisa memindai file lokal harddisk komputer Anda, sehingga aplikasi kamera HP mengalami gangguan / *force close*.

Pilih salah satu cara mudah agar bisa sinkron:

  • Opsi A (Paling Mudah): Unggah file ini ke layanan hosting HTML gratisan seperti Tiiny.host, Vercel, atau GitHub Pages. Setelah online, scan QR Code akan lancar 100%!
  • Opsi B (Lokal Server - Satu WiFi): Jalankan program server lokal (misalnya ekstensi Live Server di VS Code, atau XAMPP), lalu buka alamat IP komputer Anda di browser (misalnya: http://192.168.1.15:5500).

Scan kode QR di bawah menggunakan kamera HP Anda untuk membuka, mengedit, dan mencentang tabel ini secara sinkron dan otomatis.
